# ndt_omp_ros2

本包提供基于 PCL 衍生、经 OpenMP 加速的 Normal Distributions Transform（NDT）及 GICP 算法。NDT 算法经过 SSE 友好改造并实现多线程化，运行速度可达 PCL 原版的最多 10 倍。
