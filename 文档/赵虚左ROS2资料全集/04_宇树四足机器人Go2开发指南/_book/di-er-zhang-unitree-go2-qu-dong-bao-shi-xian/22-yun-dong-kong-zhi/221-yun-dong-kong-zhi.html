2.2.1 运动控制

2.2.1 运动控制

1.消息类型

Go2机器人的运动指令是通过请求响应的方式实现的，通过订阅/api/sport/request，并发送运动 unitree_api::msg::Request 消息可以实现高层的运动控制。

通过调用如下指令可以获取运动控制对应的消息接口类型：

ros2 topic type /api/sport/request

其输出结果为：unitree_api/msg/Request。

2.数据结构

通过如下指令，可以获取运动控制消息接口的数据结构：

ros2 interface show unitree_api/msg/Request

其输出结果如下：

RequestHeader header //请求头
    RequestIdentity identity //请求身份标识，用于唯一标识请求的来源和类型。
        int64  id //请求的唯一标识符（ID），一般用当前时间戳表示。
        int64 api_id //运动模式的标识符，每种运动模式都有其唯一标识符
    RequestLease lease
        int64 id // 表示租约id，一般默认0即可。
    RequestPolicy policy //请求的策略配置，用于定义请求的优先级和处理方式。
        int32 priority //请求的优先级，1表示高优先级会优先处理，0按照先入先出顺序处理。
        bool noreply //是否不需要回复。如果为 true，服务器在处理完请求后不会发送响应。
string parameter //请求的参数，是一个字符串，用于传递具体的控制指令
uint8[] binary // 请求参数的二进制形式

RequestHeader.RequestIdentity.api_id可用值如下：

1001: 阻尼控制
1002: 平衡站立，控制机器人进入平衡站立状态，保持直立和稳定
1003: 停止运动，停止机器人的所有运动，使其立即静止
1004: 站立，控制机器人从其他姿势（如坐下或躺下）恢复到站立姿势
1005: 站立下降，控制机器人从站立姿势转变为其他姿势（如坐下或躺下）
1006: 恢复站立，控制机器人在失去平衡后恢复到站立姿势
1007: 欧拉角控制，用于调整机器人的姿态（如俯仰、横滚、偏航）
1008: 移动，控制机器人进行移动，可能是直线移动或转向
1009: 坐下，控制机器人进入坐下姿势
1010: 从坐下恢复站立，控制机器人从坐下姿势恢复到站立姿势
1011: 切换步态，切换机器人的步态（如行走、跑步、爬行等）
1012: 触发，可能用于触发某个特定的动作或事件
1013: 身体高度调整，调整机器人的身体高度
1014: 脚部抬起高度调整，调整机器人脚部的抬起高度
1015: 速度级别调整，调整机器人的运动速度级别
1016: 打招呼，控制机器人执行“打招呼”的动作
1017: 伸展，控制机器人执行“伸展”动作
1018: 轨迹跟随，控制机器人按照预定的轨迹进行移动
1019: 连续步态，控制机器人进行连续的步态运动
1020: 内容，可能用于控制机器人显示或执行某种内容（如播放视频或音频）
1021: 打滚，控制机器人执行“打滚”或“翻滚”动作
1022: 舞蹈1，控制机器人执行第一种舞蹈动作
1023: 舞蹈2，控制机器人执行第二种舞蹈动作
1024: 获取身体高度，获取机器人当前的身体高度
1025: 获取脚部抬起高度，获取机器人当前脚部的抬起高度
1026: 获取速度级别，获取机器人当前的运动速度级别
1027: 切换操纵杆，切换操纵杆的控制模式或功能
1028: 姿态，控制机器人进入特定的姿态或姿势
1029: 刮擦，控制机器人执行“刮擦”动作
1030: 前空翻，控制机器人执行前空翻动作
1031: 前跳，控制机器人执行前跳动作
1032: 前扑，控制机器人执行前扑动作

parameter是一个特定格式的字符串， 示例如下：

{"x": 0.2, "y": 0.0, "z": 0.5} // x对应纵向上的线速度，y对应横向上的线速度，z对应偏航的角速度

接口定义的源文件为：~/unitree_ros2/cyclonedds_ws/src/unitree/unitree_api/msg/Request.msg。

3.内置例程

运动控制的完整例程位于~/unitree_ros2/example/src/sport_mode_ctrl.cpp。

编译完例程后，在终端中进入unitree_ros2/example目录并运行如下指令：

./install/unitree_ros2_example/bin/sport_mode_ctrl

等待 1s 后，机器人会沿着 X 方向来回走动。
